# FRAME CINEMAS frontend

The React and TypeScript frontend for FRAME CINEMAS.

See the [project README](../README.md) for features, architecture, local setup, testing, and deployment information.

## Commands

```bash
npm run dev        # start the Vite development server
npm test           # run the frontend tests once
npm run test:watch # run tests in watch mode
npm run build      # type-check and create a production build
npm run lint       # run ESLint
```
